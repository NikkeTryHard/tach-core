# Implementation Plan: v0.1.3 and v0.1.4

> Design document for implementing Error Handling/Diagnostics (0.1.3) and Dependency Updates (0.1.4)

---

## Overview

This plan covers two milestone releases:

1. **v0.1.3 - Error Handling and Diagnostics**: Enhance user-facing error messages, add debugging flags, and improve self-test output
2. **v0.1.4 - Dependency Updates**: Modernize Rust dependencies, update to Rust 2024 edition, and test compatibility

---

## Current State Analysis

### What Already Exists

**Error Handling (`src/core/errors.rs`):**

- Unified `TachError` enum with domain-specific variants
- `CategorizedError` struct with E001-E010 error codes
- `ErrorCategory::User` vs `ErrorCategory::System` categorization
- `suggestions` module for context-aware fix suggestions
- `from_tach_error()` and `from_anyhow()` conversion methods

**Diagnostics (`src/core/diagnostics.rs`):**

- `tach self-test` command with kernel/capability checks
- `--diagnose` flag with categorized output (System, Capabilities, Python, Performance)
- `DiagnosticResult` and `DiagnosticReport` structures
- Individual checks: kernel, userfaultfd, landlock, seccomp, jemalloc, ptrace, python

**CLI (`src/core/config.rs`):**

- `--diagnose` flag already implemented
- `-v` / `-vv` verbosity levels
- Subcommands: `Test`, `List`, `SelfTest`, `Version`

### What Needs to Be Added

**v0.1.3:**

- Error codes E011-E020 for additional failure modes
- `--debug` flag for verbose syscall logging
- `--trace` flag for maximum verbosity (RUST_LOG=trace equivalent)
- Enhanced self-test with inline remediation suggestions
- `docs/errors.md` error reference documentation

**v0.1.4:**

- Rust 2024 edition migration
- Dependency version updates
- `cargo audit` security fixes
- PyPy compatibility testing

### Task 2: Add --debug and --trace Flags

**File:** `src/core/config.rs`

```rust
// In Cli struct:

/// Enable debug logging (verbose syscall traces).
///
/// Outputs detailed syscall information to stderr for debugging
/// isolation and sandbox issues. Equivalent to RUST_LOG=debug.
#[arg(long)]
pub debug: bool,

/// Enable trace logging (maximum verbosity).
///
/// Outputs all internal state changes and system calls.
/// Use for deep debugging. Equivalent to RUST_LOG=trace.
#[arg(long)]
pub trace: bool,
```

**File:** `src/main.rs`

Update main to configure logging based on flags:

```rust
fn configure_logging(cli: &Cli) {
    let level = if cli.trace {
        "trace"
    } else if cli.debug {
        "debug"
    } else if cli.verbose >= 2 {
        "debug"
    } else if cli.verbose >= 1 {
        "info"
    } else {
        "warn"
    };

    std::env::set_var("RUST_LOG", format!("tach_core={}", level));
    // Note: Logging should be initialized before this in actual impl
}
```

### Task 3: Enhance Self-Test Output with Remediation

**File:** `src/core/diagnostics.rs`

Extend `DiagnosticResult` to include remediation:

```rust
#[derive(Debug, Clone)]
pub struct DiagnosticResult {
    pub name: String,
    pub passed: bool,
    pub message: String,
    pub details: Option<String>,
    pub required: bool,
    /// New: Specific remediation command or steps
    pub remediation: Option<Remediation>,
}

#[derive(Debug, Clone)]
pub struct Remediation {
    /// Shell command to fix the issue
    pub command: Option<String>,
    /// URL to documentation
    pub docs_url: Option<String>,
    /// Human-readable explanation
    pub explanation: String,
}
```

Update each check to provide remediation:

```rust
pub fn check_userfaultfd() -> DiagnosticResult {
    // ... existing logic ...
    DiagnosticResult::fail("userfaultfd", "Disabled")
        .with_remediation(Remediation {
            command: Some("sudo sysctl vm.unprivileged_userfaultfd=1".to_string()),
            docs_url: Some("https://github.com/NikkeTryHard/tach-core/blob/master/docs/troubleshooting.md#userfaultfd".to_string()),
            explanation: "Enable unprivileged userfaultfd for memory snapshots".to_string(),
        })
}
```

## Risk Assessment

| Risk                              | Mitigation                                                       |
| --------------------------------- | ---------------------------------------------------------------- |
| Rust 2024 edition breaks code     | Run `cargo fix --edition`, test thoroughly                       |
| PyO3 update breaks Python binding | Keep PyO3 version conservative, test on multiple Python versions |
| New error codes break JSON schema | Update JSON schema tests                                         |
| Debug logging impacts performance | Only enable when flag is set                                     |
