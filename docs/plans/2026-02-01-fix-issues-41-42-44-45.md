## Batch 1: Fix CI Integration Tests (Issue #41)

**Goal:** Add integration test job to CI workflow so tests in `tests/` and `rust_tests/` run in CI.

#### Task 1.1: Add Integration Tests Job

**Files:**
- Modify: `.github/workflows/ci.yml`

**Step 1: Understand current state**
The `unit-tests` job on line 77 runs:
```yaml
run: cargo nextest run --lib --all-features --profile ci
```
The `--lib` flag restricts to library unit tests only.

**Step 2: Add integration-tests job**
Add after the `unit-tests` job (after line 78):

```yaml

  integration-tests:
    name: Integration Tests
    runs-on: ubuntu-latest
    needs: check
    steps:
      - uses: actions/checkout@v6

      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable

      - name: Install mold linker
        run: sudo apt-get install -y mold

      - name: Setup sccache
        uses: mozilla-actions/sccache-action@v0.0.9

      - name: Install nextest
        uses: taiki-e/install-action@nextest

      - name: Cache cargo
        uses: Swatinem/rust-cache@v2

      - name: Install Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"

      - name: Install Python dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pytest pytest-asyncio pytest-django django

      - name: Set PYO3_PYTHON
        run: echo "PYO3_PYTHON=$(which python)" >> $GITHUB_ENV

      - name: Run integration tests
        run: cargo nextest run --all-features --profile ci
```

**Step 3: Verify locally**
Run: `cargo nextest run --all-features --profile ci`
Expected: All tests run including integration tests in `tests/` and `rust_tests/`

**Step 4: Commit**
```bash
git add .github/workflows/ci.yml
git commit -m "fix(ci): add integration tests job to CI workflow

Closes #41"
```

## Batch 2: Fix Silent Test Passes and Private Attribute Access (Issues #42, #44)

**Goal:** Refactor test_effect_flow.py to use pytest.importorskip and public properties.

#### Task 2.1: Replace Silent Pass Pattern with importorskip

**Files:**
- Modify: `tests/pytest_asyncio/test_effect_flow.py`

**Step 1: Understand current problematic patterns**
Lines 27 and 54 have:
```python
if "tach_harness" in sys.modules:
    # test logic
# else: silently passes
```

Lines 72-73 have:
```python
assert manager._current_scope == "module"
assert manager._auto_mode is True
```

**Step 2: Refactor the entire file**
Replace the entire file content with:

```python
"""Test that asyncio effects flow from conftest to worker.

This module verifies that:
1. The AsyncioSetup HookEffect is correctly converted to Python dict in zygote.rs
2. The apply_cached_effects function in tach_harness.py handles asyncio_setup
3. EventLoopManager is configured correctly from the effect
"""
import pytest

# Skip entire module if tach_harness is not available
tach_harness = pytest.importorskip("tach_harness")


# This test verifies that loop_scope configured in conftest
# is correctly applied to the EventLoopManager

@pytest.mark.asyncio
async def test_asyncio_marker_detected():
    """Verify basic async test runs."""
    import asyncio
    loop = asyncio.get_running_loop()
    assert loop is not None


@pytest.mark.asyncio
async def test_event_loop_manager_singleton():
    """Verify EventLoopManager singleton pattern works."""
    from tach_harness import EventLoopManager
    manager1 = EventLoopManager.get_instance()
    manager2 = EventLoopManager.get_instance()
    assert manager1 is manager2


@pytest.mark.asyncio(loop_scope="class")
class TestClassScopedLoop:
    """Tests with class-scoped loop."""

    async def test_first_in_class(self):
        import asyncio
        assert asyncio.get_running_loop() is not None

    async def test_second_in_class(self):
        import asyncio
        assert asyncio.get_running_loop() is not None


@pytest.mark.asyncio
async def test_asyncio_effect_application():
    """Test that AsyncioSetup effect can be applied via apply_cached_effects."""
    from tach_harness import apply_cached_effects, EventLoopManager, EFFECT_TYPE_ASYNCIO_SETUP

    # Simulate an asyncio setup effect
    effects = [
        {
            "type": EFFECT_TYPE_ASYNCIO_SETUP,
            "loop_scope": "module",
            "auto_mode": True,
        }
    ]

    # Apply the effect
    applied = apply_cached_effects(effects)
    assert applied == 1

    # Verify EventLoopManager was configured using public properties
    manager = EventLoopManager.get_instance()
    assert manager.current_scope == "module"
    assert manager.auto_mode is True

    # Reset to default for other tests
    manager.configure("function", False)
```

**Step 3: Verify the refactor**
Run: `pytest tests/pytest_asyncio/test_effect_flow.py -v`
Expected: Tests either run (if tach_harness available) or skip with clear message

**Step 4: Commit**
```bash
git add tests/pytest_asyncio/test_effect_flow.py
git commit -m "refactor(tests): use importorskip and public properties in effect_flow tests

- Replace 'if tach_harness in sys.modules' with pytest.importorskip
- Use public properties current_scope and auto_mode instead of private _current_scope and _auto_mode

Closes #42
Closes #44"
```
