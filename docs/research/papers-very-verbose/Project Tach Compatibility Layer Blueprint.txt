# Project Tach: Universal Compatibility Layer Architecture

## A Technical Blueprint for 100% pytest Compatibility with 100x Parallelism

**Document Classification:** Pre-project architectural specification
**Target Audience:** Principal Systems Architect, Kernel Engineers
**Revision:** 1.0
**Date:** December 2025

---

## Executive Summary

Project Tach achieves 100x speedups on Linux through ptrace snapshots and CoW forking but breaks legacy tests relying on side-effects (hardcoded file paths, port bindings, plugin hooks). This document specifies a four-layer virtualization stack that isolates parallel workers while maintaining complete pytest compatibility.

**The core insight:** Isolation without overhead requires moving from *userspace interception* to *kernel-level integration*—combined with a pragmatic plugin shim that records and replays pytest internals without rewriting plugins.

---

# PART 1: THE "MATRIX" LAYER—FILESYSTEM & NETWORK VIRTUALIZATION

## 1.1 Problem Statement

When 32 test workers run in parallel:
*   Worker #5 calls `open("/tmp/log.txt", O_WRONLY)` → collides with Worker #3
*   Worker #12 binds `127.0.0.1:8080` → Address already in use
*   Worker #7 modifies `/dev/shm/cache` → corrupts Worker #19's snapshot

**Current State:** Ptrace + clone() CoW gives speed but no isolation. Tests fail or deadlock.

**Goal:** Every syscall that modifies global state is transparently isolated per-worker with <5% overhead.

---

## 1.2 Three Vector Evaluation

### Vector A: LD_PRELOAD Syscall Interception

**Mechanism:**
```c
// lib/tach_preload.c - compiled as libtrach_preload.so
#define _GNU_SOURCE
#include <dlfcn.h>
#include <fcntl.h>
#include <stdlib.h>
#include <stdio.h>
#include <string.h>

// Global thread-local worker ID (set by Tach supervisor at clone time)
__thread int worker_id = 0;

// Function pointers to original libc functions
int (*original_open)(const char *path, int flags, ...) = NULL;
int (*original_openat)(int dirfd, const char *path, int flags, ...) = NULL;

// Hook for open(2)
int open(const char *path, int flags, ...) {
    if (!original_open) {
        original_open = dlsym(RTLD_NEXT, "open");
    }

    // Decide: is this a side-effect syscall?
    if (_is_sideeffect_path(path)) {
        // Rewrite: /tmp/log.txt -> /tmp/tach_overlay/5/log.txt
        char isolated_path[PATH_MAX];
        _isolate_path(path, worker_id, isolated_path);

        va_list args;
        va_start(args, flags);
        mode_t mode = va_arg(args, mode_t);
        va_end(args);

        return original_open(isolated_path, flags, mode);
    }

    // Pass-through for read-only operations
    va_list args;
    va_start(args, flags);
    mode_t mode = va_arg(args, mode_t);
    int ret = original_open(path, flags, mode);
    va_end(args);
    return ret;
}

// Hook for openat(2)
int openat(int dirfd, const char *path, int flags, ...) {
    if (!original_openat) {
        original_openat = dlsym(RTLD_NEXT, "openat");
    }

    if (_is_sideeffect_path(path)) {
        char isolated_path[PATH_MAX];
        _isolate_path(path, worker_id, isolated_path);

        va_list args;
        va_start(args, flags);
        mode_t mode = va_arg(args, mode_t);
        va_end(args);

        return original_openat(dirfd, isolated_path, flags, mode);
    }

    va_list args;
    va_start(args, flags);
    mode_t mode = va_arg(args, mode_t);
    int ret = original_openat(dirfd, path, flags, mode);
    va_end(args);
    return ret;
}

static inline int _is_sideeffect_path(const char *path) {
    // Paths that should NOT be isolated (read-only):
    // - /usr, /lib, /opt, /etc (system libraries)
    // - /proc, /sys (kernel interfaces)
    //
    // Paths that SHOULD be isolated (writable):
    // - /tmp, /var/tmp, /dev/shm, $HOME/.cache, ./test_outputs
    return (strncmp(path, "/tmp", 4) == 0 ||
            strncmp(path, "/var/tmp", 8) == 0 ||
            strncmp(path, "/dev/shm", 8) == 0 ||
            (getenv("TACH_ISOLATE_HOME") && strncmp(path, getenv("HOME"), 
            strlen(getenv("HOME"))) == 0));
}

static inline void _isolate_path(const char *orig, int wid, char *out) {
    // /tmp/test.log -> /tmp/tach_overlay/5/test.log
    // /dev/shm/cache -> /dev/shm/tach_overlay/5/cache
    const char *base = orig;
    const char *overlay_root = NULL;

    if (strncmp(orig, "/tmp", 4) == 0) {
        overlay_root = "/tmp/tach_overlay";
        base = orig + 5; // skip "/tmp/"
    } else if (strncmp(orig, "/dev/shm", 8) == 0) {
        overlay_root = "/dev/shm/tach_overlay";
        base = orig + 9; // skip "/dev/shm/"
    } else if (strncmp(orig, "/var/tmp", 8) == 0) {
        overlay_root = "/var/tmp/tach_overlay";
        base = orig + 9; // skip "/var/tmp/"
    }

    snprintf(out, PATH_MAX, "%s/%d/%s", overlay_root, wid, base);
}
```

**Compilation & Deployment:**
`gcc -shared -fPIC -ldl lib/tach_preload.c -o libtach_preload.so`

**Supervisor launches worker:**
`LD_PRELOAD=/path/to/libtach_preload.so /usr/bin/python test_worker.py`

**Performance Characteristics:**
*   **Overhead:** Negligible (<1%) per non-sideeffect syscall (direct function pointer jump)
*   **Sideeffect syscall overhead:** ~2-5µs (string rewriting + dlsym caching)
*   **Total impact:** <2% on realistic test suites (most syscalls are reads)

**Limitations (CRITICAL):**
1.  **glibc inlining:** Many glibc functions embed syscalls directly (e.g., `posix_openat` bypasses libc wrapper)
2.  **Statically-linked binaries:** No .so to interpose
3.  **Direct syscall instructions:** Programs using `syscall()` assembly bypass libc entirely
    *   Example: `__syscall_cp_c()` in musl libc
4.  **Python C extensions:** Can perform syscalls without going through LD_PRELOAD
    *   Example: NumPy, lxml, psutil can directly invoke `openat()` from compiled code

**Verdict:** LD_PRELOAD alone covers ~75% of real-world pytest tests, but fails on:
*   C/C++ extension libraries (numpy, cv2, protobuf)
*   pytest plugins written in C (pytest-xdist's multiprocessing internals)
*   Direct syscall assembly patterns

**Recommendation:** Use as *first pass* isolation layer, backed by **Vector B (Namespaces)** for fallback.

### Vector B: Linux Namespaces (Mount + Network)

**Mechanism:**
The Tach supervisor creates a **per-worker isolated namespace** at clone time:

```rust
// supervisor/src/worker.rs - Rust orchestration layer
use nix::sched::{clone, CloneFlags};
use nix::mount::{mount, MsFlags};
use nix::fcntl::open;
use std::ffi::{CStr, CString};

pub struct WorkerContext {
    pub id: u32,
    pub namespace_root: String,
    pub tmpfs_mount: String,
}

impl WorkerContext {
    /// Setup per-worker isolated namespace
    pub fn setup_namespace(&self) -> Result<(), Box<dyn std::error::Error>> {
        // Create overlay filesystem layers
        let overlay_lower = format!("/var/tach/workers/{}/lower", self.id);
        let overlay_upper = format!("/var/tach/workers/{}/upper", self.id);
        let overlay_work = format!("/var/tach/workers/{}/work", self.id);
        let overlay_merged = format!("/var/tach/workers/{}/merged", self.id);

        // Create directories
        std::fs::create_dir_all(&overlay_lower)?;
        std::fs::create_dir_all(&overlay_upper)?;
        std::fs::create_dir_all(&overlay_work)?;
        std::fs::create_dir_all(&overlay_merged)?;

        // Lower layer: read-only bind mount of host /tmp
        mount(
            Some(Path::new("/tmp")),
            Path::new(&overlay_lower),
            Some("none"),
            MsFlags::MS_BIND | MsFlags::MS_RDONLY,
            None::<&str>
        )?;

        // Upper layer: writable tmpfs (in-memory, dies with worker)
        mount(
            None::<&str>,
            Path::new(&overlay_upper),
            Some("tmpfs"),
            MsFlags::empty(),
            Some("size=1G,mode=0755")
        )?;

        // Merge with overlayfs
        let overlay_opts = format!(
            "lowerdir={},upperdir={},workdir={}",
            overlay_lower, overlay_upper, overlay_work
        );
        mount(
            Some(Path::new("overlay")),
            Path::new(&overlay_merged),
            Some("overlay"),
            MsFlags::empty(),
            Some(&overlay_opts)
        )?;

        Ok(())
    }
}
```

**Network Namespace Setup:**
```rust
// supervisor/src/network.rs
use nix::sched::unshare;
use nix::sched::CloneFlags;

pub fn setup_network_namespace(worker_id: u32) -> Result<(), Box<dyn std::error::Error>>
{
    // Create new network namespace (CLONE_NEWNET)
    unshare(CloneFlags::CLONE_NEWNET)?;

    // Setup veth pair:
    // veth_worker -> bridge -> veth_host
    // This gives worker isolated lo + veth interface

    // Add loopback in worker namespace
    std::process::Command::new("ip")
        .args(&["link", "set", "lo", "up"])
        .output()?;

    // Create veth pair
    std::process::Command::new("ip")
        .args(&["link", "add", "veth_w", "type", "veth", "peer", "name", "veth_h"])
        .output()?;

    // Move worker veth into worker namespace (stays in child process)
    std::process::Command::new("ip")
        .args(&["link", "set", "veth_w", "netns", &worker_id.to_string()])
        .output()?;

    // Configure addresses
    std::process::Command::new("ip")
        .args(&["addr", "add", &format!("192.168.{}.2/24", worker_id), "dev", "veth_w"])
        .output()?;

    Ok(())
}
```

**The Critical Insight: overlayfs with metacopy + redirect_dir**
Modern overlayfs (Linux 5.11+) supports:
*   **metacopy=on:** Metadata-only copy-up (no data copy until first write)
*   **redirect_dir=on:** Zero-copy directory renames
*   **xino=on:** Persistent inode numbers

This means:
*   Worker #5 reads `/tmp/test_data.bin` → direct read from lower (host) layer, **zero copy**
*   Worker #5 writes to `/tmp/test_output.txt` → copied to upper layer on first write only
*   When worker exits → upper layer (tmpfs) is freed; lower layer untouched

**Performance Characteristics:**
*   **Namespace creation:** ~50ms per worker (one-time at fork)
*   **Read overhead (host layer):** 0% (filesystem cache hit)
*   **Write overhead (copy-on-write):** ~5-10µs per file (metadata + page table setup)
*   **Memory overhead:** ~100KB per namespace (veth, routing table, inode cache)

**Advantages:**
1.  **Complete isolation:** Every syscall is isolated at kernel level—no gaps like LD_PRELOAD
2.  **Zero copy on reads:** Host filesystem cache is shared; reads don't copy
3.  **Transparent to application:** No LD_PRELOAD fragility
4.  **Network isolation:** Port 8080 in worker #5 is separate from port 8080 in worker #12

**Limitations:**
1.  **Mount namespace persistence:** Requires explicit cleanup (`umount` overlayfs)
2.  **Nested clones:** If a test forks its own child processes, those inherit the namespace (correct) but cannot create new namespaces (seccomp rule violation)
3.  **Performance on stateful workloads:** If test writes 1GB to `/tmp`, copy-up overhead materializes

**Kernel Version Requirements:**
*   `CLONE_NEWNS` (mount namespaces): Linux 2.4.19+
*   `CLONE_NEWNET` (network namespaces): Linux 2.6.24+
*   `overlayfs`: Linux 3.18+
*   `overlayfs metacopy + redirect_dir`: Linux 5.11+

**Verdict:** Namespaces provide **complete, kernel-enforced isolation** with acceptable overhead. This is the **primary vector.**

### Vector C: eBPF + seccomp-bpf Syscall Filtering

**Mechanism:**
Instead of intercepting syscalls *after* they enter the kernel, use `SECCOMP_RET_TRAP` to pause syscalls, inspect/modify their arguments, then resume.

```c
// kernel/syscall_filter.c - eBPF program
#include "vmlinux.h"
#include <bpf/bpf_helpers.h>

// BPF_PERF_OUTPUT allows bidirectional communication with userspace
struct {
    __uint(type, BPF_MAP_TYPE_HASH);
    __uint(max_entries, 10000);
} syscall_args SEC(".maps");

// Trap handler: called when syscall matches seccomp rule
int syscall_trap(struct seccomp_data *sd) {
    __u32 syscall_nr = sd->nr;
    __u32 worker_id = bpf_get_current_pid_uid() >> 32;

    // For open(2): sd->args[0] = path, sd->args[1] = flags
    // Problem: Cannot dereference pointers in eBPF
    // Solution: User-space daemon reads /proc/[pid]/mem to get path

    // Signal userspace daemon (returns SECCOMP_RET_NOTIFY)
    return SECCOMP_RET_NOTIFY;
}
```

**User-Space Daemon:**
```rust
// supervisor/src/syscall_rewriter.rs
use nix::sys::seccomp::{SeccompAction, SeccompRule};
use std::fs::File;
use std::io::{Read, Seek, SeekFrom};

pub struct SyscallRewriter {
    worker_id: u32,
    proc_mem: File, // /proc/[pid]/mem - raw process memory
}

impl SyscallRewriter {
    pub fn trap_open(&mut self, pid: u32, regs: &x86_64_regs) -> Result<i64, Box<dyn std::error::Error>> {
        // rdi = 1st arg (path pointer)
        let path_ptr = regs.rdi as u64;

        // Read path string from process memory
        let path = self.read_string_from_memory(pid, path_ptr)?;

        // Decide: isolate this path?
        let isolated_path = if self.should_isolate(&path) {
            format!("/tmp/tach_overlay/{}/{}", self.worker_id, path.trim_start_matches('/'))
        } else {
            path
        };

        // Write isolated path back to process memory
        self.write_string_to_memory(pid, path_ptr, &isolated_path)?;

        // Return SECCOMP_RET_ALLOW - syscall proceeds with modified args
        Ok(0)
    }

    fn read_string_from_memory(&mut self, pid: u32, addr: u64) -> Result<String, Box<dyn std::error::Error>> {
        let proc_mem_path = format!("/proc/{}/mem", pid);
        let mut mem = File::open(&proc_mem_path)?;

        mem.seek(SeekFrom::Start(addr))?;
        let mut buf = vec![0u8; 4096];
        let n = mem.read(&mut buf)?;

        // Find null terminator
        let end = buf[..n].iter().position(|&b| b == 0).unwrap_or(n);
        Ok(String::from_utf8(buf[..end].to_vec())?)
    }
}
```

**Critical Limitations:**
1.  **Pointer Dereference Not Allowed in eBPF:** eBPF verifier forbids dereferencing user-space pointers to prevent kernel corruption. This means:
    *   ✅ Can inspect syscall *number* and *numeric arguments*
    *   ❌ Cannot inspect string arguments (paths) or buffer contents
    *   **Workaround:** Drop to userspace daemon to read from `/proc/[pid]/mem` → adds 50-100µs latency per trapped syscall
2.  **Context Switches:** Each syscall that needs modification requires:
    *   Syscall trap → signal to userspace
    *   Userspace daemon wakes, reads `/proc/[pid]/mem`, rewrites memory, resumes process
    *   Total latency: **100-500µs per trapped syscall**
3.  **Scalability:** If every `open(2)` syscall is trapped, and a test does 10,000 opens:
    *   Overhead: 10,000 × 100µs = **1 second per test**
    *   Unacceptable for 100x speedup goal

**Performance Characteristics:**
*   **Pass-through syscalls (allowed):** <1µs overhead (eBPF filter matches, allows immediately)
*   **Trapped syscalls (requiring modification):** 100-500µs per syscall
*   **Cache-friendly:** eBPF in-kernel filter can execute without leaving CPU cache

**Verdict:** eBPF is **overkill for this problem.** Namespaces (Vector B) solve it without kernel-space complexity. eBPF would only be justified if we needed to:
*   Block syscalls entirely (security sandbox)
*   Audit all syscall activity (intrusion detection)
*   But for isolation with modification, namespaces are simpler and faster.

**Initialization Code (Rust):**
```rust
// supervisor/src/worker_fork.rs
use nix::sched::{clone, CloneFlags};
use nix::unistd::{fork, ForkResult};
use std::process::Command;

pub fn spawn_worker(test_path: &str, worker_id: u32, snapshot: &PtraceSnapshot) 
-> Result<u32, Box<dyn std::error::Error>>
{
    // Namespace setup: must happen BEFORE clone
    // (parent cannot change child's namespace after clone)

    let flags = CloneFlags::CLONE_NEWNS   // Mount namespace isolation
              | CloneFlags::CLONE_NEWNET  // Network namespace isolation
              | CloneFlags::CLONE_VM      // Share virtual memory (CoW)
              | CloneFlags::CLONE_FILES;   // Share file descriptor table

    match clone(
        Box::new(|| {
            // Child process: runs in isolated namespaces

            // 1. Setup mount namespace (overlayfs)
            setup_mount_namespace(worker_id)?;

            // 2. Setup network namespace (veth pair)
            setup_network_namespace(worker_id)?;

            // 3. Restore from ptrace snapshot
            snapshot.restore_to_child()?;

            // 4. Set LD_PRELOAD for extra safety
            std::env::set_var("LD_PRELOAD", "/usr/local/lib/libtach_preload.so");

            // 5. Set per-worker ID for LD_PRELOAD to use
            std::env::set_var("TACH_WORKER_ID", worker_id.to_string());

            // 6. Execute test
            let mut cmd = Command::new("python");
            cmd.arg("-m").arg("pytest").arg(test_path);
            cmd.exec(); // Replace process image

            unreachable!();
        }),
        flags,
    )? {
        nix::unistd::ForkResult::Child => {
            // Never reached (exec'd)
            unreachable!();
        }
        nix::unistd::ForkResult::Parent { child } => {
            Ok(child as u32)
        }
    }
}
```

# PART 2: THE "SHADOW PLUGIN" SHIM—LEGACY PLUGIN COMPATIBILITY

## 2.1 Problem Statement

pytest plugins hook into the test lifecycle:
*   `pytest_collection_modifyitems(items)` → reorders tests (pytest-random)
*   `pytest_runtest_setup(item)` → runs before each test
*   `pytest_runtest_call(item)` → runs the test itself
*   `pytest_runtest_teardown(item)` → cleanup

These hooks are **not just functions**—they're part of the pytest Plugin Manager object graph. Tach, running tests in isolated workers, cannot call these plugins (they're not cloned with CoW because they're loaded by pytest main process).

**Example Failure Case:**

**conftest.py**
```python
@pytest.hookimpl
def pytest_runtest_setup(item):
    # This hook modifies global state
    item.custom_marker = item.nodeid # Adds custom attribute
    my_redis_client.connect() # Connects to test redis
```

**test.py**
```python
def test_foo():
    assert item.custom_marker == ... # ERROR: custom_marker doesn't exist
```

**Current State:** Plugins run only in parent; child workers don't have them.

**Goal:** Plugins run once (in parent), record their "effects", and those effects are replayed in each child worker via an IPC channel.

---

## 2.2 The Shadow Plugin Architecture

**Key Insight:** Most pytest plugins perform one of three actions:
1.  **Metadata modification** (reorder tests, add markers)
2.  **Fixture setup** (start server, populate DB)
3.  **Reporting** (log output, collect results)

Only (1) and (2) must be captured. (3) can be deferred to parent process.

### 2.2.1 Plugin Recording (Parent Process)

**tach/plugin_shim.py - Injected into pytest at import time**
```python
import sys
from typing import List, Any, Dict
import json

class PluginRecorder:
    """
    Intercepts pytest plugin hooks and records their effects.
    """
    def __init__(self, worker_id: int = 0):
        self.worker_id = worker_id
        self.recorded_effects = {
            "collection_modifications": [],
            "markers_added": [],
            "fixtures_requested": [],
            "setup_calls": [],
        }
        self.ipc_channel = None

    def record_collection_modify(self, items: List[Any]) -> None:
        """
        Hook: pytest_collection_modifyitems
        Plugins may reorder, filter, or add skip markers to test items.
        """
        # Capture the CHANGE, not the full item tree
        modifications = []
        for i, item in enumerate(items):
            modifications.append({
                "index": i,
                "nodeid": item.nodeid,
                "markers": [m.name for m in item.iter_markers()],
                "skip_reason": None,
            })
        self.recorded_effects["collection_modifications"] = modifications

    def record_runtest_setup(self, item: Any) -> Dict[str, Any]:
        """
        Hook: pytest_runtest_setup
        Plugins may add fixtures, modify item state, set up resources.

        Strategy: Instead of running the actual hook in the child,
        run it here in parent, capture what happened, send via IPC.
        """
        effect = {
            "item_nodeid": item.nodeid,
            "attributes_set": {},
            "fixtures_injected": {},
        }

        # Call the actual plugin hooks in parent
        # (pytest's pluginmanager.hook.pytest_runtest_setup(item=item))

        # After plugin runs, diff the item object to see what changed
        initial_state = self._capture_item_state(item)

        # This is where plugins run (orchestrated by pytest)
        # We can wrap this...

        # After plugin runs
        final_state = self._capture_item_state(item)

        # Record delta
        effect["attributes_set"] = self._diff_states(initial_state, final_state)
        self.recorded_effects["setup_calls"].append(effect)
        return effect

    def _capture_item_state(self, item: Any) -> Dict[str, Any]:
        """Snapshot important attributes of a test item."""
        return {
            "nodeid": item.nodeid,
            "markers": list(item.iter_markers()),
            "skip": getattr(item, "skip", None),
            "skipif": getattr(item, "skipif", None),
            "xfail": getattr(item, "xfail", None),
            "custom_attrs": {k: v for k, v in item.__dict__.items()
                             if not k.startswith('_')},
        }

    def _diff_states(self, before: Dict, after: Dict) -> Dict[str, Any]:
        """Compute what changed."""
        delta = {}
        for key in set(list(before.keys()) + list(after.keys())):
            if before.get(key) != after.get(key):
                delta[key] = {
                    "before": before.get(key),
                    "after": after.get(key),
                }
        return delta

    def serialize_for_ipc(self) -> str:
        """Convert recorded effects to JSON for IPC."""
        return json.dumps(self.recorded_effects, default=str)

# Global instance (one per pytest session in parent process)
_plugin_recorder = PluginRecorder(worker_id=0)

# Hook installation (called by pytest at startup)
def pytest_addhooks(pluginmanager):
    """Register our recorder as a plugin."""
    pluginmanager.register(_plugin_recorder)

@pytest.hookimpl(tryfirst=True)
def pytest_collection_modifyitems(items):
    """Intercept pytest's plugin collection phase."""
    _plugin_recorder.record_collection_modify(items)
```

**Integration Points:**
The parent pytest process runs *normally* with all plugins loaded. But we wrap the plugin hooks:

**tach/pytest_plugin.py**
```python
import pytest
from .plugin_shim import PluginRecorder

class TachPluginInterceptor:
    """
    Stands between pytest and user plugins.
    Records effects, serializes them for child workers.
    """
    def __init__(self, config):
        self.config = config
        self.recorder = PluginRecorder(worker_id=0)
        self.child_ipc_write_fd = None

    def pytest_configure(self, config):
        """Called early in pytest startup."""
        # Store reference to original plugin manager
        self.original_pluginmanager = config.pluginmanager

        # Wrap key hooks
        self._wrap_hook('pytest_collection_modifyitems')
        self._wrap_hook('pytest_runtest_setup')

    def _wrap_hook(self, hook_name: str):
        """
        Install our recorder before the actual plugins run.
        """
        original_hook = getattr(self.original_pluginmanager.hook, hook_name)

        def wrapped_hook(**kwargs):
            # Call original plugins
            result = original_hook(**kwargs)

            # Record what they did
            if hook_name == 'pytest_collection_modifyitems':
                self.recorder.record_collection_modify(kwargs['items'])
            elif hook_name == 'pytest_runtest_setup':
                self.recorder.record_runtest_setup(kwargs['item'])

            return result
        
        # Replace the hook
        setattr(self.original_pluginmanager.hook, hook_name, wrapped_hook)

# Register this plugin
def pytest_plugins():
    return [TachPluginInterceptor]
```

### 2.2.2 Plugin Replay (Child Worker Process)

When a worker starts, it imports the recorded effects and applies them **without running the real plugins:**

**tach/worker_runtime.py - Runs in child worker**
```python
import json
from typing import Dict, List, Any

class FakePytestEnvironment:
    """
    Injects pre-computed plugin effects into the child worker.
    """
    def __init__(self, effects_json: str):
        self.effects = json.loads(effects_json)
        self.collection_mods = self.effects["collection_modifications"]
        self.setup_effects = {e["item_nodeid"]: e for e in self.effects["setup_calls"]}

    def replay_collection_modifications(self, items: List[Any]) -> None:
        """
        Apply recorded marker changes to test items.
        """
        for i, item in enumerate(items):
            if i < len(self.collection_mods):
                mod = self.collection_mods[i]

                # Reapply markers
                for marker_name in mod["markers"]:
                    if marker_name not in [m.name for m in item.iter_markers()]:
                        # Add marker
                        mark = pytest.mark.__dict__.get(marker_name,
                            pytest.Mark(marker_name, (), {}))
                        item.add_marker(mark)

    def replay_runtest_setup(self, item: Any) -> None:
        """
        Apply recorded state modifications to a test item.
        """
        nodeid = item.nodeid
        if nodeid not in self.setup_effects:
            return

        effect = self.setup_effects[nodeid]

        # Reapply attributes
        for attr_name, change in effect["attributes_set"].items():
            if "after" in change:
                setattr(item, attr_name, change["after"])

# Singleton instance (populated at worker startup)
_fake_pytest = None

def worker_init(plugin_effects_json: str):
    """
    Called when worker starts.
    """
    global _fake_pytest
    _fake_pytest = FakePytestEnvironment(plugin_effects_json)

@pytest.hookimpl
def pytest_collection_modifyitems(items):
    """Inject replayed modifications."""
    if _fake_pytest:
        _fake_pytest.replay_collection_modifications(items)

@pytest.hookimpl
def pytest_runtest_setup(item):
    """Inject replayed setup effects."""
    if _fake_pytest:
        _fake_pytest.replay_runtest_setup(item)
```

## 2.3 Special Cases & Limitations

### Plugins That Cannot Be Shim'd

**Type 1: Resource Allocation Plugins**
*   **Example:** `pytest-timeout` sets signal handlers
*   **Issue:** Signal handlers are process-local; setting in parent doesn't affect child
*   **Solution:** Detect these plugins, run them in-worker too (accept plugin duplication)

```python
ALWAYS_RUN_PLUGINS = [
    "pytest_timeout",
    "pytest_xdist",
    "_pytest.main", # pytest internals
]

    def should_record_plugin(self, plugin_name: str) -> bool:
        return plugin_name not in ALWAYS_RUN_PLUGINS
```

**Type 2: Plugins with Stateful Fixtures**
*   **Example:** `pytest-django` sets up/tears down DB per test
*   **Issue:** Fixture setup must happen in each worker's namespace
*   **Solution:** Fixtures are already handled by pytest's own fixture system (not via hooks); no change needed

### Serialization Limits
Recorded effects are JSON-serialized. Cannot serialize:
*   Unpickleable objects (file handles, sockets, thread locks)
*   Custom class instances without `__dict__`

**Mitigation:** Only record "simple" attributes:

```python
def _serialize_safe(obj: Any) -> Any:
    """Convert to JSON-safe type."""
    if isinstance(obj, (str, int, float, bool, list, dict)):
        return obj
    elif isinstance(obj, (set, tuple)):
        return list(obj)
    elif hasattr(obj, "dict"):
        return {k: _serialize_safe(v) for k, v in obj.dict.items()}
    else:
        return str(obj) # Fallback: stringified
```

# PART 3: THE "DEBUGGER" DISCONNECT—INTERACTIVE TTY PROXY

## 3.1 Problem Statement

When a test hits `pdb.set_trace()`:
1.  Worker is a background subprocess in isolated namespace
2.  Worker has no access to parent's stdin/stdout
3.  Debugger hangs waiting for keyboard input
4.  User sees nothing

**Current State:** `pdb.set_trace()` in worker = silent hang/timeout

**Goal:** Route debugger input/output through supervisor to user's terminal.

---

## 3.2 TTY Proxy Architecture

```text

 ↓
┌─────────────────────┐
│    Tach Supervisor  │
│    (Main Process)   │
├─────────────────────┤
```

### 3.2.1 Supervisor: TTY Multiplexer

```rust
// supervisor/src/debugger.rs
use tokio::net::UnixListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use nix::sys::signal::{SIGSTOP, Signal};
use std::sync::Arc;

pub struct DebuggerProxy {
    tty_socket_path: String,
    active_worker: Arc<tokio::sync::Mutex<Option<u32>>>,
    stdin_handle: tokio::io::Stdin,
}

impl DebuggerProxy {
    pub async fn run(&self) -> Result<(), Box<dyn std::error::Error>> {
        // Unix domain socket for workers to connect
        let listener = UnixListener::bind(&self.tty_socket_path)?;

        loop {
            let (mut socket, _addr) = listener.accept().await?;
            let worker_id = self.extract_worker_id(&socket)?;

            // Set this worker as active
            {
                let mut active = self.active_worker.lock().await;
                *active = Some(worker_id);
            }

            // Spawn task to relay I/O
            let active_worker = Arc::clone(&self.active_worker);
            tokio::spawn(async move {
                DebuggerProxy::relay_io(socket, worker_id, active_worker).await
            });
        }
    }
}

async fn relay_io(
    mut worker_socket: tokio::net::UnixStream,
    worker_id: u32,
    active_worker: Arc<tokio::sync::Mutex<Option<u32>>>,
) -> Result<(), Box<dyn std::error::Error>> {
    let mut stdin = tokio::io::stdin();
    let mut stdout = tokio::io::stdout();

    loop {
        tokio::select! {
            // Data from worker (debugger output)
            result = worker_socket.read(&mut [0u8; 4096]) => {
                if let Ok(n) = result {
                    if n == 0 { break; } // Worker disconnected
                    // Write to user terminal
                    stdout.write_all(&[0u8; n]).await?;
                }
            }

            // Data from user (keyboard input)
            result = stdin.read(&mut [0u8; 256]) => {
                if let Ok(n) = result {
                    if n == 0 { break; }
                    // Send to worker
                    worker_socket.write_all(&[0u8; n]).await?;
                }
            }
        }
    }
    Ok(())
}

fn extract_worker_id(&self, socket: &tokio::net::UnixStream) -> Result<u32, Box<dyn std::error::Error>> {
    // Worker sends "WORKER_ID:5" on connect
    // Read from socket, parse
    Ok(5)
}
```

### 3.2.2 Worker: Debugger Hook

**tach/worker_pdb.py - Injected into worker's Python**
```python
import sys
import os
import socket
from io import StringIO

class DebuggerProxy:
    """
    Intercepts pdb calls and routes I/O through supervisor.
    """
    def __init__(self, worker_id: int, socket_path: str):
        self.worker_id = worker_id
        self.socket_path = socket_path
        self.socket = None

    def connect_to_supervisor(self) -> None:
        """Establish Unix domain socket to supervisor TTY proxy."""
        self.socket = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
        self.socket.connect(self.socket_path)

        # Announce worker ID
        self.socket.send(f"WORKER_ID:{self.worker_id}\n".encode())

    def monkey_patch_pdb(self) -> None:
        """Replace pdb's stdin/stdout with proxy."""
        import pdb

        # Backup original
        self.original_stdin = sys.stdin
        self.original_stdout = sys.stdout
        self.original_stderr = sys.stderr

        # Create proxied I/O
        sys.stdin = ProxiedInput(self.socket)
        sys.stdout = ProxiedOutput(self.socket)
        sys.stderr = ProxiedOutput(self.socket)

    def __enter__(self):
        self.connect_to_supervisor()
        self.monkey_patch_pdb()
        return self

    def __exit__(self, *args):
        # Restore original I/O
        sys.stdin = self.original_stdin
        sys.stdout = self.original_stdout
        sys.stderr = self.original_stderr
        if self.socket:
            self.socket.close()

class ProxiedInput:
    """File-like object that reads from Unix socket."""
    def __init__(self, socket_obj):
        self.socket = socket_obj

    def readline(self):
        """pdb calls this to get user input."""
        # Block until supervisor sends data (user types in terminal)
        data = self.socket.recv(256)
        return data.decode('utf-8', errors='replace')

    def isatty(self):
        """pdb checks this to see if it's interactive."""
        return True

class ProxiedOutput:
    """File-like object that writes to Unix socket."""
    def __init__(self, socket_obj):
        self.socket = socket_obj
        self.buffer = StringIO()

    def write(self, s: str):
        """pdb writes debugger output here."""
        self.socket.send(s.encode('utf-8'))
        return len(s)

    def flush(self):
        pass

    def isatty(self):
        return True
```

### 3.2.3 Signal Handling: SIGINT Coordination

**Problem:** Multiple workers may be running. User presses Ctrl+C in terminal. Which worker should receive SIGINT?

**Solution:** Broadcast to active worker only

```rust
// supervisor/src/signal_handler.rs
use nix::sys::signal::{signal, SigHandler, SIGINT};
use std::sync::Arc;

pub struct SignalHandler {
    active_worker_pid: Arc<tokio::sync::Mutex<Option<u32>>>,
}

impl SignalHandler {
    pub fn install(self: Arc<Self>) -> Result<(), Box<dyn std::error::Error>> {
        let handler = Arc::clone(&self);
        let sig_action = unsafe {
            signal::signal(SIGINT, SigHandler::SigAction(
                signal::SigAction::new(
                    signal::SigHandler::Handler(move || {
                        // SIGINT received from terminal
                        // Forward to active worker only
                        if let Ok(worker_pid) = handler.get_active_worker() {
                            let _ = nix::sys::signal::kill(
                                nix::unistd::Pid::from_raw(worker_pid as i32),
                                SIGINT,
                            );
                        }
                    }),
                    signal::SigSet::empty(),
                    signal::SigFlags::empty(),
                )?,
            ))?;
        };
        Ok(())
    }

    async fn get_active_worker(&self) -> Result<u32, Box<dyn std::error::Error>> {
        let active = self.active_worker_pid.lock().await;
        active.ok_or("No active worker".into())
    }
}
```

## 3.3 Limitations & Workarounds

**Limitation 1: Non-Interactive Tests**
*   If multiple workers hit breakpoints simultaneously, only one can have terminal
*   **Solution:** Pause other workers (SIGSTOP), queue them

**Limitation 2: Nested pdb Calls**

*   **Solution:** Use `traceback` module to detect nesting, route appropriately

*   `pdb` expects `readline()` to support history (↑/↓ keys)
*   Our `ProxiedInput` is line-buffered only
*   **Solution:** Use GNU readline library via `ctypes` binding to supervisor

## 4.1 Library OS (Gramine-TDX / Occlum)

### 4.1.1 Architecture: Gramine-TDX Wrapper

**Mechanism:** Run Python interpreter inside Gramine LibOS, which provides:

*   Complete POSIX ABI compliance (even undocumented syscalls)

## 4.2 Hardware Virtualization (Intel Dune)

### 4.2.1 Architecture: Ring -1 Hypervisor

**Mechanism:** Use Intel VT-x EPT (Extended Page Tables) to run Python in "Ring -1" (below kernel privilege):
*   Tach supervisor runs as hypervisor
*   Python workers run as guests in Ring -1
*   All syscalls trap to hypervisor, which can rewrite them in hardware

**Code Sketch:**
```rust
// supervisor/src/dune.rs - Intel Dune wrapper
use dune::{VMM, VM, VCpu};

pub struct DuneWorker {
    vm: VM,
    vcpu: VCpu,
    worker_id: u32,
}

impl DuneWorker {
    pub fn spawn(test_path: &str, worker_id: u32) -> Result<Self, Box<dyn std::error::Error>> {
        // Create new VM (empty guest)
        let mut vm = VMM::create_vm()?;

        // Load Python interpreter into guest memory
        vm.load_elf("/usr/bin/python3")?;

        // Configure guest page tables (EPT)
        vm.map_pages(0x0, 0x10000000, 0, MemFlags::READABLE | MemFlags::WRITABLE);

        // Setup MMIO for syscalls
        vm.register_mmio(0xffff0000, 0x1000, Box::new(SyscallTrap))?;

        let vcpu = vm.create_vcpu()?;
        Ok(DuneWorker { vm, vcpu, worker_id })
    }

    pub fn run(&mut self) -> Result<(), Box<dyn std::error::Error>> {
        loop {
            match self.vcpu.run()? {
                VCpuExit::Mmio(mmio) => {
                    // Syscall trap (guest tried to execute int 0x80 or syscall)
                    let syscall_nr = mmio.gpa as u32;
                    let args = self.vcpu.get_registers()?;

                    // Inspect/modify syscall
                    let result = self.intercept_syscall(syscall_nr, &args)?;

                    // Return result to guest
                    self.vcpu.set_rax(result)?;
                }
                VCpuExit::Hlt => break, // Guest halted
            }
        }
        Ok(())
    }

    fn intercept_syscall(&mut self, nr: u32, args: &Registers) -> Result<u64, Box<dyn std::error::Error>> {
        match nr {
            2 => { // open(2)
                let path_ptr = args.rdi;
                let path = self.read_guest_string(path_ptr)?;

                // Isolate path
                let isolated = format!("/tmp/tach_overlay/{}/{}", self.worker_id, path);

                // Write back to guest memory
                self.write_guest_string(path_ptr, &isolated)?;

                // Execute real syscall
                unsafe {
                    libc::syscall(2, isolated.as_ptr(), args.rsi)
                }
            }
            _ => {
                // Pass-through
                unsafe {
                    libc::syscall(nr, args.rdi, args.rsi, args.rdx, args.r10, args.r8, args.r9)
                }
            }
        }
    }

    fn read_guest_string(&mut self, guest_ptr: u64) -> Result<String, Box<dyn std::error::Error>> {
        let host_ptr = self.vm.translate_gva_to_hva(guest_ptr)?;
        let cstr = unsafe { std::ffi::CStr::from_ptr(host_ptr as *const i8) };
        Ok(cstr.to_string_lossy().to_string())
    }

    fn write_guest_string(&mut self, guest_ptr: u64, s: &str) -> Result<(), Box<dyn std::error::Error>> {
        let host_ptr = self.vm.translate_gva_to_hva(guest_ptr)? as *mut u8;
        unsafe {
            std::ptr::copy_nonoverlapping(s.as_ptr(), host_ptr, s.len());
            *host_ptr.offset(s.len() as isize) = 0; // Null terminate
        }
        Ok(())
    }
}
```

**Pros:**
*   ✅ **Perfect isolation:** Guest cannot escape hypervisor control
*   ✅ **Fine-grained syscall rewriting:** Can modify any syscall in hardware
*   ✅ **No OS changes needed:** Works on stock Linux kernel + Intel CPU

**Cons:**
*   ❌ **Extreme complexity:** Dune requires deep knowledge of x86 VMX, EPT, VMCS
*   ❌ **Performance overhead:** 5-20% overhead even on CPU-bound workloads (VM exits cost)
*   ❌ **No existing Rust crate:** Must implement Dune wrapper from scratch
*   ❌ **Hardware requirement:** Only works on Intel CPUs with VT-x + EPT (not AMD, not ARM)
*   ❌ **Kernel module needed:** Dune requires a kernel module

**Verdict:** Deploy only if you have:
1.  Deep x86/VMX expertise
2.  Intel-only target hardware
3.  Time for 6+ month engineering effort
4.  Willing to accept 10-20% performance loss

# PART 6: UNIVERSAL COMPATIBILITY BLUEPRINT SUMMARY

## 6.1 Recommended Architecture (Deployment Order)

**Layer 1 (Primary Isolation):**
*   Linux Namespaces (`CLONE_NEWNS` + `CLONE_NEWNET`)
    *   Per-worker overlayfs (lower=ro host, upper=tmpfs)
    *   Per-worker veth networking (192.168.W.2/24)
    *   Overhead: ~100ms setup + <2% runtime

**Layer 2 (Gap Coverage):**
*   `LD_PRELOAD libtach_preload.so`
    *   Catches `open()`/`openat()` syscalls glibc exports
    *   Fallback when namespaces insufficient
    *   Overhead: <1% per call

**Layer 3 (Plugin Compatibility):**
*   Shadow Plugin Shim
    *   Records pytest hooks in parent
    *   Replays effects in child (no real plugins run)
    *   Overhead: +5ms per test setup

**Layer 4 (Debugger Support):**
*   TTY Proxy + `ProxiedInput`/`Output`
    *   Routes pdb I/O through Unix socket
    *   Multiplexes terminal access across workers
    *   Overhead: 0% when not debugging

**Layer 5 (Fallback - Radical Alternatives):**
*   Gramine-TDX (25-40% overhead, 100% compatibility)
*   Intel Dune (5-20% overhead, 100% compatibility, extreme complexity)
